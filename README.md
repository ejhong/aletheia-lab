# Aletheia Lab

A place to run AI experiments on big open questions: ancient mysteries, consciousness, physics, undeciphered
scripts.

The lab is the workshop next to [Aletheia](https://ejhong.github.io/aletheia/), which maps contested claims to
evidence. The lab produces evidence; Aletheia judges it, through its own process.

- **[QUESTIONS.md](QUESTIONS.md)**: the questions, each with an issue. Only questions marked `status:active` are
  worked on, two at most.
- **[AGENTS.md](AGENTS.md)**: the rules every agent follows.
- **[docs/LOCKING.md](docs/LOCKING.md)**: how a question's plan is locked before results are seen.
- **[SPENDING.md](SPENDING.md)**: every paid run.
- **[The site](https://ejhong.github.io/aletheia-lab/)**: built from `site/` by `scripts/build_site.py` on every push to
  `main`.

Null results are published like any other. Many of these questions will end with "no mystery here", and that's a
result.

The work is done by AI agents (Claude and others, named in each result), directed by Eugene Jhong.

The name was used earlier by a September 2026 experiment, archived at
[ejhong/aletheia-lab-2026-09](https://github.com/ejhong/aletheia-lab-2026-09).
