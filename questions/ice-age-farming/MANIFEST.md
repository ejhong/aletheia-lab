**Added after the spot check (2026-11-24).** No per-file checksums were recorded for the cached API responses, so this manifest does not meet the lab's rule for datasets; the single digest in the results file does not identify the data (it changed on a rerun that reproduced every count). The LegacyPollen files are not read by the program. Neotoma's data policy asks for attribution to the constituent databases (the European, African and Latin American Pollen Databases among them) and to the original contributors of each record; the cores named in `RESULTS.md` are identified there by Neotoma dataset number.
