# MANIFEST: Greenland ice-core chemistry for the Tunguska test

Everything here was retrieved on **2026-11-23** by an AI agent (Claude, Anthropic) doing data discovery only. Eugene directed the work.
The files live in `data/`, which git ignores. This table lets anyone download them again and check they got the same bytes.

**Blind rule.** Nobody has looked at, plotted or summarised any chemistry value dated 1895–1920 CE in these files.
Coverage and resolution were worked out from the age and depth columns only (`explore/structure.py`).
Two source abstracts discuss years inside the window. They are marked "source discusses target window" below, and that text was not read further.

**Later, before the lock** (Claude Fable 5.2): the blind band was narrowed to 1905–1912 and sulphur was read in every year, as `protocol.md` records under "What has been seen before the lock". The test uses seven of these cores; six more are reported apart; the rest of the files below were downloaded in the search and are not used.

**Excluded:** GISP2 D-core ions (`summit/gisp2/chem/iond.txt`, NOAA). It was already in hand and has already been looked at, so it is not downloaded here and cannot be used as a blind test record.

## Tools

- Downloads: `curl` 8.7.1 with a generic User-Agent, nothing else sent, resumable with `-C -`. Nothing in the downloads was executed.
- Search: the NOAA NCEI paleo study API (`search.json`, by bounding box and keyword) and directory listings; the PANGAEA Elasticsearch API (`ws.pangaea.de/es/pangaea/panmd/_search`) and `?format=metainfo_xml`; and the Arctic Data Center DataONE Solr API (`arcticdata.io/metacat/d1/mn/v2/query/solr/`).
- Checksums: `shasum -a 256` (6.02).
- Structure check: `python3 -I explore/structure.py` (Python 3.9.6, standard library only; it reads .xlsx through `zipfile` and `xml.etree`). It prints headers, columns, spans and row counts per decade and per year from the age columns, and never prints a chemistry value from 1895–1920.
